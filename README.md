# Wedding Invitation - Mohammed Ziya & Aysha Nooha

A beautiful wedding invitation website for the wedding of Mohammed Ziya and Aysha Nooha on August 1st, 2026.

## Deploy to Vercel

1. Push this folder to a GitHub repository
2. Go to [vercel.com](https://vercel.com)
3. Click "New Project"
4. Import your GitHub repository
5. Vercel will auto-detect Vite and deploy

Or use Vercel CLI:
```bash
npm install -g vercel
vercel
```

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Features

- Animated falling hearts
- Background music (autoplay on interaction)
- Live countdown timer
- Responsive design
- RSVP functionality
- Google Maps integration
- Beautiful animations
